# CMTS Android

**Chassis Master Test Suite — 手机端 Standalone MVP**  
当前版本：**0.1.3**（`versionCode` 4）· 包名 `com.cmts.mobile` · 显示名 CMTS

手机端 GNSS + IMU 采集、Compose 地图仪表、会话导出、姿态/坡度、回放曲线，以及独立的 **Performance Test（车辆性能测试）**（含回放离线计分）模块。定位源可在手机 GNSS 与外接 UM982 之间切换，并可通过局域网连接 Windows 客户端。  
Windows 客户端（`Chassis Master Test Suite`）为本仓库只读参考，**不在此仓库修改**。

Agent / 开发入口：[AGENTS.md](AGENTS.md) · [CONTEXT_INDEX.md](CONTEXT_INDEX.md) · 最新交接见 `docs/GROKBOT_HANDOFF_2026-11-06_RELEASE.md`。

## 项目简介 / Overview

CMTS Android 面向底盘与动力学路测场景：在真机上以前台服务采集原始 GNSS/IMU（及气压等），地图上叠加轨迹与浮动仪表面板，支持录制、回放曲线、VBO/KML/CSV 导出；0.1.1 起含可多选阈值段的性能测试；**0.1.2** 补齐实时预览、姿态归零/起步标定、俯仰坡度、轨迹选色、回放离线计分与带速度/海拔的 KML。**0.1.3** 增加局域网 Smart LAN 连接；其后合入 USB 外接 UM982 定位源、连续性能测试与回放通道/安装归零（版本号仍为 0.1.3）。

**验证边界（请务必阅读）**

- 性能测试引擎单测与构建已通过；**未宣称室外实车验收通过**。质量门限为调参建议，不是已验证规格。
- 阈值穿越使用相邻有效样本**线性插值**，制动距离为速度折线**梯形积分**；插值只用于估计穿越时刻，**不宣称提高了 GNSS 测量精度**。
- 成绩计算使用原始 GNSS 速度与采样时间戳，**禁止**用 UI 刷新数据或历史回放抽样当成绩输入。
- Google 地图瓦片授权与高德 Key 仅限本机配置；发布级授权仍为开放项。

## 主要功能 / Features（0.1.3 及后续合入）

### 地图与界面

- **Google 卫星图** / **高德标准图**切换（高德 Key 在本机 `local.properties` 的 `AMAP_API_KEY`，勿提交）。
- 深色 + 香槟金（`#D4AF37`）视觉；地图全屏铺底 + 浮动面板；**轨迹颜色可自定义**（12 色色板 + RGB，实时/历史共用并持久化）。
- **竖屏**：底部 BottomSheet；半开 / 全开后左右翻页（仪表、成绩、姿态等）；上拉全屏后可左右滑切换分页，底部小圆点指示。
- **横屏**：窄栏 / 展开栏上下翻页；窄栏四个数为**竖直一列**，并可看成绩与俯仰/侧倾；旋转保留当前页；系统栏安全区（观感仍以真机用户验收为准）。
- 竖屏 / 横屏**启动图**（`SplashActivity` + `drawable-nodpi` / `drawable-land-nodpi`）。

### 采集与传感器

- 前台 `CaptureService`：GNSS、加速度、陀螺、旋转矢量；车辆坐标映射（见 ADR-002：`X=device.Y`，`Y=-device.X`，`Z=device.Z`）。App 可见时即可绑定预览刷新仪表；显式开始记录才创建会话。
- 主界面可在**手机 GNSS**与**外接 UM982**（CH344Q USB 串口 NMEA）之间切换；选择会记住，默认手机 GNSS。离开 USB 调试页后，串口仍在后台继续收数；选择外接源后，无有效定位时**不会**悄悄退回手机 GNSS。
- NMEA 按同一 UTC 历元合并为一次定位；轨迹按定位历元更新（外接模块常为 20 Hz）；半开仪表刷新与展开 Dashboard 一致（约 10 Hz 界面上限）。应用**不向 UM982 发送配置命令**。真机插拔与室外精度**未宣称验收通过**。
- Dashboard：**去重力线加速度**显示；姿态 / 陀螺**归零与复位**（仅显示偏置，CSV 仍写原始含重力加速度）；可选**直线向前起步标定**车身 X 正向。
- **车辆姿态页**：可转动左视图（俯仰）与后视图（侧倾），旁侧实时角度；**坡度**按 `100 × tan(俯仰°)`（车头向下为正俯仰约定，上坡为正）。
- 卫星可见 / 参与定位数；**气压**（`TYPE_PRESSURE`，摘要与 CSV；旧会话缺通道显示 `—`）。
- 高度标签为 GNSS 椭球相关高度，**不直接宣称平均海平面海拔**。

### 车辆姿态估算（实验对照）

- 独立纯 Kotlin 自适应四元数互补滤波，使用系统交付的加速度计、陀螺仪和测量时间戳；动态时降低加速度倾斜校正，陀螺继续追踪真实转动。没有角度缩小、硬限幅或强制归零。
- 原 `vehicle.attitude` 仍来自 Android `TYPE_ROTATION_VECTOR`；新结果写入独立 `estimate.*` 通道，不替换原始 IMU、系统姿态、性能成绩或坡度计算。车身俯仰不等于道路坡度。
- 手机 GNSS 速度和可靠运动方向用于运动门控。外接 HPR 航向/RMC 运动方向尚未充分区分，新门控不使用该混合字段；**定量 GNSS 加速度补偿未启用**。
- 记录权重、拒绝原因、数据年龄、距可信校正时间、初始状态、零偏、算法版本及参数。传输新增独立 `estimate.attitude/status`，保留旧协议字段含义；Windows 对新增字段的显示尚未实机验收。
- 六轴 Yaw 无长期绝对参考；缓慢增长且平稳的加速度仍可能产生伪倾角。质量规则不是已验证的角度精度或概率置信区间。

### 录制 · 回放 · 导出

- 已保存会话支持姿态「重算」：逐行处理原始 CSV，独立输出 `attitude-recomputed.csv`，不覆盖原记录。必须包含完整停车初始化历史及算法上下文；旧文件或中途才开始录制、缺少必要历史的文件会明确拒绝重算。

- 会话录制与原始 CSV / 元数据；历史列表紧凑行；左滑删除（保护当前写入目录）。
- 本地会话回放（播放 / 暂停、进度、0.5×–8×）；**回放曲线**通道与 Live 对齐（速度 / 俯仰 / 侧倾 / 三轴加速度等、时间窗与共享游标）；若会话保存了安装归零，回放按同一归零显示。与 Live 隔离。外部「打开 VBO」仍为文件页预览，**不等于**主界面通用回放。
- **回放离线计分**：设定速度边界后逐段出结果；读原始 `samples.csv` phone.gps，复用性能引擎，写 `result-vN.json`（不覆盖原始）。
- 导出：**VBO**、**KML**（`gx:Track` + 原始 GNSS 海拔 / 速度 m/s / 水平精度；旧记录可从手机原始会话重新导出）、**CSV**（原样 `samples.csv`）。ZIP 入口已移除，原始文件仍保留。

### 局域网连接（0.1.3）

- Android 作为 WebSocket 服务端，在局域网发布 CMTS 发现信息；Windows 可自动发现并双击连接。
- Dashboard 常驻区仅显示「电脑连接」状态及「连接详情」。状态区分未连接、已连接、已订阅数据和通信已关闭；订阅状态不代表已经验证数据传输质量。
- 二维码、网络地址、设备发现详情、复制连接串及启动/停止通信服务收进详情弹窗；移除无法可靠判断的常驻热点提示。自动发现与通信服务仍保留。
- 支持无 token 的 `device.hello`，协议版本仍会校验；同一局域网可访问的客户端均可连接，这是当前单人使用模式。
- 设备型号单独提供；例如 SM-N9860 显示为 Samsung Galaxy Note20 Ultra 5G。连接二维码只含设备与网络元数据。
- Windows 目前只支持同时连接一台手机；公网和多设备并行采集尚未实现。

### 定位源与 USB

- 主界面定位源切换、后台收数与历元合并见上文「采集与传感器」。
- CH344Q（VID `1A86` / PID `55D5`）四口串口全部监听，并显示各口字节计数。
- 独立 `UsbDebugActivity`：WCH UART（`CH34XUartDriver.jar`）枚举 / 授权 / 波特率 / HEX·ASCII / 保存。
- 应用**不**发送设备配置协议。真机 OTG 插拔与室外精度**未宣称验收通过**。

### Performance Test（性能测试）

- 四种段类型可**多选**：起步加速 `0→X`、区间加速 `X→Y`、区间制动 `X→Y`、停车制动 `X→0`；阈值用户可改。
- 一次跑程（如 0–100–0）可同时输出多项成绩；表列含测试时间、类型、**时间**与**距离**（制动类）。
- 计分**默认开启**：跑完后保持待命并自动再次进入可记录状态，可连续多组；点取消才关闭连续计分。开始新的录制会清空成绩表，只显示本轮。
- **待命**后自动判起止；质量标识（PASS/WARN/FAIL）与原因；历史尝试与**重算**（新 `result-vN`，不覆盖原始成绩）。
- 纯 Kotlin 引擎 `perf-engine-1.0.0`，实时与离线重算共用；速度源跟随当前定位源（手机 GNSS 或已切换的外接 UM982）。
- 静止 / 异常过滤 / 缺样 / 超时 / 换源等规则见引擎与单测；零速与门限参数随尝试保存。

## 使用教程 / How to use

### 安装

1. 获取 debug APK（自行 `assembleDebug`，或见 [Releases](https://github.com/aneminence/CMTS-Android/releases) 说明）。
2. 手机开启「安装未知应用」；若系统用地图/网盘打开 `.apk`，请改用**软件包安装程序**。
3. 覆盖安装（`adb install -r`）可保留应用数据；**安装前确认未在录制**。

### 权限与省电

- 需要**精确定位**；性能测试待命也会拉起采集持有。
- 三星等机型省电可能导致锁屏后唤醒锁受限、CSV 停写；长期路测请按交接说明检查省电 / 电池优化（已验证场景不等于全部机型验收）。

### 定位源

1. 在主界面选择「手机 GNSS」或「外接 UM982」。
2. 外接模块经 USB 串口输出 NMEA（常见 115200 8N1）。可先在 USB 调试页确认有数据；回到主界面并离开该页后，后台仍会继续收数。
3. 应用不会改写模块配置；输出频率与语句以模块当前设置为准。

### 竖屏面板

1. 半开 / 全开后左右翻页查看仪表、性能测试、姿态等。
2. 底部分页小点指示当前页。
3. 内容区优先滚动；滚到边界后再拖面板收起（手感以真机为准）。

### 横屏面板

1. 旋转后面板在物理底边一侧；拖**把手** Peek → 半开 → 全屏。半开四个数为竖直一列。
2. 全屏后**上下滑**切换 Dashboard / 性能测试。
3. Dashboard 横屏为紧凑模块布局并可横向浏览内容（与竖屏上下滚对应「轴转 90°」产品意图；布局仍可能继续打磨）。

### 普通录制与回放

1. 授权定位后点开始记录；结束后在「记录与文件」查看会话。
2. 点已保存会话进入主界面轨迹 + Dashboard 回放；导出用行内 VBO / KML / CSV。

### 性能测试

有关姿态实验模块的启用见下节；性能测试继续使用原有 GNSS 成绩链路。

1. 全屏面板滑到 **性能测试** 页。
2. 勾选需要的测试段，填写起/终速度（km/h）；两个加速一行、两个制动一行。
3. 计分默认已开启并保持连续待命，跑完不必再点待命；点取消才关闭连续计分（仍可与普通录制独立持有 GNSS；停止录制不会无提示杀掉性能 hold）。
4. 按段自动起止；下方成绩表新增行（时间、类型、成绩含距离/时间）。开始新的普通录制时，成绩表会清空，只显示本轮。
5. 点历史行可看详情并**重算**（新版本结果，不覆盖原始）。

界面文案亦提示：**原始 GNSS 速度；插值不提高精度。**

### 姿态估算启用、校准与回退

1. 当前仅支持固定安装约定：**屏幕朝上、手机顶部朝车头**。未知安装航向不能仅靠重力确定；原显示归零不是新滤波器初始化。
2. Dashboard 打开「车辆姿态估算 · 实验对照」，选择手机 GNSS。在可靠定位下停车，点击「确认已停车：校准陀螺零偏与初始化」，保持稳定至少 3 秒。
3. 初始化要求速度 <0.2 m/s、速度精度 ≤0.3 m/s 及连续稳定 IMU；不满足时保持初始化，不填充假姿态。零偏只在这次可信停车校准中更新，运动时冻结。
4. 长采样空白或饱和后标记姿态无效，需重新停车校准。关闭对照开关可隐藏新结果；原系统姿态和原归零功能始终保留。
5. 若需要离线重算，**先开始记录，再完成停车校准**。保存后在「记录与文件」点「重算」，生成独立派生 CSV；缺少原始数据或初始化历史时不会反造数据。

2026-11-11 验证：143 项单元测试通过，APK 构建和 Lint 通过；Note20 Ultra 已验证安装、横竖屏、后台返回、独立 CSV 写入与连接详情弹窗。指定理想 5/20 秒阶跃及真实倾角组合测试满足 ≤1° 开发目标，**不是手机实测精度承诺**。缓增加速度加偏置/噪声场景最大伪俯仰约 1.70°；缺参考偏置场景残余侧倾约 3.38°。实机当时无可靠 GNSS 速度，户外停车校准完成、动态融合与独立参考精度仍未验收。详见[交付与验证报告](docs/vehicle-attitude-delivery.md)。

## 构建说明 / Build

环境：Android Studio（建议捆绑 JBR）、AGP / Gradle 以工程为准；`compileSdk`/`targetSdk` 35，`minSdk` 26；Kotlin / Compose 见 `gradle` 配置。

PowerShell，仓库根目录：

```powershell
$env:JAVA_HOME='C:/Program Files/Android/Android Studio/jbr'
./gradlew.bat --offline --console=plain assembleDebug testDebugUnitTest lintDebug
```

需要拉依赖时可用本机代理，例如 `127.0.0.1:7897`（见 `scripts/Verify.ps1 -ProxyHost ...`）。官方 Gradle Wrapper 已包含。

调试安装示例：

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb -s <serial> install -r app\build\outputs\apk\debug\app-debug.apk
```

可选：`scripts/check_elf_alignment.py` 检查 64 位 SO LOAD 对齐（高德 16KB 相关；**不等于**已在真 16KB 页手机上验收）。

### 不纳入 Git

`evidence/`、`local.properties`、`.toolchain/`、构建产物、`*.apk` / `*.aab` 等已 gitignore，请本地重建。

- 回放与导出：本地会话回放倍速；KML/CSV/VBO；USB 调试页（WCH）。
- 版本号：`versionName 0.1.1` / `versionCode 2`。
