# ADR-003: Google satellite tiles (direct URL, unauthorized for shipping)

- Status: Accepted (product choice) / Open (licensing & China network)
- Date: 2026-11

## Context
User required Google basemap parity with the Windows client’s direct tile style. Phone loads successfully; emulator may time out.

## Decision
Use Google Satellite XYZ tiles, e.g. `https://mt0.google.com/vt/lyrs=s&x={x}&y={y}&z={z}`. Keep a small © Google attribution; no large “Google Satellite” badge. Cache only currently visible tiles in memory — no bulk offline Google cache.

## Consequences
- Accessibility on one phone ≠ commercial license or release readiness. **Do not claim free commercial authorization.**
- Do not switch back to OSM (or another provider) without asking the user.
- Formal licensing and domestic network stability remain open (see `docs/tasks.md`).

## 2026-11-05 用户请求的交互优化
用户要求减少拖动缩放重复加载，调整为最多 160 块会话内存缓存（标准 256px ARGB 约 40 MiB），最多 4 个并行请求，仅请求当前视口，无磁盘离线缓存或批量预取。缩放使用已缓存层级过渡。无 GNSS 默认视图为天津东丽区附近 39.086,117.314 / zoom 13，仅浏览，不生成定位数据。
