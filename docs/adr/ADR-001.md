# ADR-001: Jetpack Compose UI

- Status: Accepted
- Date: 2026-11

## Context
CMTS Android Standalone MVP needs a full-screen map with a floating bottom panel (two-step-road style), dark theme + champagne accent, and rapid iteration on gestures and sheets.

## Decision
Use Jetpack Compose (Material / BottomSheetScaffold patterns) for the UI layer, including the custom Canvas tile map (`MapScreen`).

## Consequences
- UI and map live in Compose; avoid introducing a parallel XML View stack for the same screens.
- Map gestures must sit in the scaffold content correctly (do not apply bottom padding that blocks touches).
- Compose pulls native graphics libs into the APK (multi-ABI); that is expected, not RK acceptance.
