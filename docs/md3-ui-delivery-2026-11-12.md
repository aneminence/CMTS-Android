# Material 3 界面更新说明

本轮界面迭代纳入 0.1.5（versionCode 6），使用 Material 3 1.4.0。

- 统一深色香槟金主题、圆角、文字层级与卡片间距。
- 仪表、性能、姿态竖屏收起面板统一高度，导航按页面数量等分。
- 录制与 GNSS 按钮统一圆角，横竖屏主文字放大居中，状态单独显示。
- 摘要数值适配宽高，单位左下对齐；横屏四列适配屏幕，详情仍可横向查看。
- 横屏顶部放置定位源、气压、水平精度、垂直精度；GNSS 列显示速度、高度、可见/定位卫星数。
- 左视车辆车头朝左，侧倾使用后视图；圆形刻度内旋转不缩放车辆，小姿态面板增加归零入口。
- 成绩表表头和内容居中、缩减行距，分段切换与内容留有间距。
- 定位源统称「外接 GNSS」，缺设备提示简化为「未检测到外接 GNSS」。

## 范围与回退

保留录制、切换、计分、回放、导出和归零操作。0.1.5 同时包含此前未提交的采集、连接及回放可靠性修复，整版差异并非仅 UI 改动。未修改 Windows 客户端和地图供应商。

修改前源码、安装包和设备数据备份保存在开发机仓库外，不上传 GitHub。覆盖安装保留应用数据，旧安装包及回退脚本仅在本地保存。

## 验证范围

发布前执行 APK 构建、单元测试和 Android Lint。界面迭代覆盖 S23 横竖屏显示与保留数据安装；构建和界面检查不代替户外 GNSS、动态姿态或实车性能验收。
