## 待开发清单（用户 2026-11-06 口述）

### 1. 数据回放 — 曲线界面

- 在数据回放界面**下方**增加曲线页/区。
- 交互与信息密度对齐 **CMTS-Win** 的曲线能力（通道选择、时间轴联动、缩放/游标等以 Windows 端现有行为为参考；具体通道集合实现前可先对照 Win 客户端只读，勿改 Win 工程）。
- 与现有轨迹回放、倍速控制同会话联动（时间游标一致）。

### 2. 数据回放 — 性能计算（复合边界条件）

- 回放场景下也能做性能计算。
- 用户设定边界条件后，**自动计算复合边界条件**下的成绩结果（多段/多选阈值组合，与实时多选段语义对齐：可对一次 0–100–0 类行程按所选起终点输出多条成绩）。
- 必须走现有 `performance` 纯引擎（实时与离线共用）；结果落盘规则遵循「新 `result-vN`，不覆盖原始」；质量原因可读。
- UI：在回放流程中提供阈值/模式设定与结果表；逐条刷新优于一次性灌满。

### 3. 车辆姿态页

- 在下方（与 Dashboard / 性能 / 回放同级或同面板体系的下一页，具体入口保持现有半开→全屏翻页/点指示器风格）增加**车辆姿态**页。
- 可视化：
  - **左视图**：可随俯仰角转动的车模；旁侧显示**实时俯仰角**。
  - **后视图**：可随侧倾角转动的车模；旁侧显示**实时侧倾角**。
- 数据源：现有车辆坐标系姿态（已有映射与归零逻辑）；展示用去重力/姿态通道，**不得反向改写原始样本**。
- 回放时也应能跟会话姿态驱动两视图（若本波只做实时，交接里写清分期）。

### 4. 轨迹颜色自定义

- 地图上轨迹颜色支持用户自定义（实时录制轨迹与历史回放轨迹至少覆盖当前产品用到的轨迹图层）。
- 偏好需持久化（进程重启仍在）；默认色保持现有深色香槟金体系可读性。
